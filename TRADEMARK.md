# FNB Trademark and Brand Guidelines

This document governs the use of the **FNB** name, logo, and related brand assets.

**FNB is not trademarked (yet), but these guidelines establish the intended usage boundaries from the start.** Formal trademark registration is recommended before the project gains significant community traction.

---

## What Is Protected

The following are considered brand assets:

- The name **"FNB"** in any capitalization (FNB, fnb)
- The full name **"FNB Open"** and **"FNB Protocol"**
- Any FNB logos, icons, or visual marks (current and future)
- The project tagline: *"Local-first personal memory operating system"*
- Domain names containing "fnb" (e.g., fnb.so, fnb.dev)
- The phrase **"FNB-compatible"** as a certification term

---

## Who Can Use the FNB Brand

### Without Permission

| Use Case | Allowed? | Conditions |
|----------|----------|------------|
| Referring to the official FNB project | ✅ Yes | Accurate attribution only |
| Linking to the official GitHub repository | ✅ Yes | Use the correct URL |
| Writing about FNB in articles, reviews | ✅ Yes | Cannot imply official endorsement |
| Using FNB in academic papers | ✅ Yes | Cite the project properly |

### With Permission

| Use Case | Allowed? | Conditions |
|----------|----------|------------|
| Creating a plugin labeled "FNB-compatible" | ⚠️ Requires certification | Must pass conformance tests |
| Using the FNB logo on a website | ⚠️ Requires permission | Cannot imply official status |
| Forking with "FNB" in the name | ⚠️ Requires disclaimer | Must clearly state it's a fork |
| Commercial use of the FNB brand | ⚠️ Requires written permission | Contact the Project Steward |

### Not Allowed

| Use Case | Allowed? | Why |
|----------|----------|-----|
| Pretending a fork is "Official FNB" | ❌ Never | Misleads users |
| Using FNB logo on unrelated products | ❌ Never | Brand dilution |
| Creating a token or coin called "FNB" | ❌ Never | Confusion with project philosophy |
| Registering "fnb" domain names for speculation | ❌ Never | Cybersquatting |
| Claiming "FNB-compatible" without certification | ❌ Never | Undermines trust |

## Logo Usage

*(Guidelines to be updated when official logos are created)*

- Do not modify, recolor, or distort the logo
- Do not animate the logo
- Do not combine the logo with other marks in a confusing way
- Maintain clear space around the logo (minimum 1x logo height)

## Official Compatibility Certification

"FNB-compatible" means the implementation passes the FNB conformance test suite.

### Certification Process

1. Implement the FNB protocol as defined in the spec
2. Run the conformance test suite
3. Submit test results for review
4. Upon approval, receive the right to display "FNB-compatible" badge

### Certified Rights

- Display "FNB-compatible" badge
- List in the official "FNB Ecosystem" page (future)
- Use the official plugin API conventions

### Certification Revocation

Certification can be revoked if the implementation:

- Falls out of conformance with the latest protocol version
- Violates data sovereignty principles
- Misuses user data
- Fails to address security vulnerabilities in a timely manner

---

## Enforcement

Violations of these guidelines should be reported to the Project Steward.

Consequences may include:
1. Cease-and-desist notice
2. Public clarification that the project is not affiliated with FNB
3. (In extreme cases) Legal action if trademark is registered and infringement occurs

---

## Future Trademark Registration

Formal trademark registration is recommended before FNB reaches significant community scale. The Project Steward retains the right to register "FNB" as a trademark in applicable jurisdictions.
