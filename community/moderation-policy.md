# Moderation Policy

## Scope

This moderation policy applies to all FNB community spaces:
- GitHub Discussions
- GitHub Issues
- Pull Request comments
- Any official FNB communication channels

## Principles

1. **Respect** — treat all community members with respect
2. **Philosophy** — stay aligned with FNB's data sovereignty and user privacy values
3. **Evidence** — make claims backed by evidence, not speculation
4. **Safety** — prioritize user safety over all other considerations

## Moderated Actions

The following actions may result in moderation:

- Harassment, discrimination, or personal attacks
- Spam or off-topic promotion
- Posting real personal data in public channels
- Attempting to bypass security or privacy controls
- Impersonating project maintainers
- Violating the Code of Conduct

## Moderation Process

1. **Warning** — private message explaining the violation
2. **Temporary restriction** — 7-30 day ban from discussions/issues
3. **Permanent ban** — for repeated or severe violations

## Appeals

Moderation decisions can be appealed by contacting the Project Steward or Core Maintainers through the security contact channel.

## Reporting

Report moderation concerns via GitHub's report feature or by contacting maintainers directly.
