# Non-Goals

FNB does not aim to:

- Build a speculative token, coin, or mining economy
- Turn user data into platform-owned AI training assets
- Replace user confirmation with AI-generated "truth"
- Become another attention-based social feed or content platform
- Become a centralized surveillance relationship graph
- Force all user data into cloud storage (local-first is default)
- Treat relationships as a simple friend list or follow graph
- Treat memory as static notes or journal entries
- Treat privacy as a settings checkbox or terms-of-service footnote
- Provide general-purpose messaging as a standalone product
- Compete with CRM, calendar, or productivity SaaS tools
- Operate as a data broker or advertising platform
- Wrap Web3 rhetoric around traditional surveillance architecture
