# Asset and MemorySource

## Asset Model

Assets in FNB represent digital media files with processing and variant support.

### Asset Types

- **Image** — photos, screenshots, illustrations
- **Audio** — voice messages, recordings, music
- **Video** — recordings, screen captures
- **Document** — PDFs, notes, exports
- **File** — generic binary content

### Asset Processing

Assets support processing pipelines:
- Image: thumbnail generation, OCR, captioning
- Audio: transcription, speaker diarization, summarization
- Video: keyframe extraction, thumbnail, transcription

Each processing step produces an `AssetVariant` and is tracked via `AssetProcessingJob`.

## MemorySource

Every Memory in FNB must trace back to a `MemorySource`:

- **chat_import** — imported from a messaging platform
- **direct_message** — sent within FNB IM
- **photo_import** — imported from camera roll
- **voice_message** — recorded or received audio
- **ai_inference** — generated by an AI model
- **manual_entry** — created directly by the user
- **system_event** — generated by the system

This ensures every piece of information in FNB has a **provenance** that can be inspected, verified, and challenged.
